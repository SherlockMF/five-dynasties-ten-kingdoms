# 934 年后唐主线阶段重建

`snapshot-934` 只覆盖 `[934, 935)`。这一版将同年可直接校勘的后唐—辽南缘和吴、吴越、闽作为阶段重建；楚、后蜀、南汉与荆南仍是可追溯的邻年推定，不把局部图拼成全国同精度定论。

## 校勘分层

- 后唐、辽南缘：依据 `atlas-page-85-later-tang`（934 年）重新概括。
- 吴、吴越、闽：分别依据 `atlas-page-89-wu`、`atlas-page-89-wuyue`、`atlas-page-89-min`（均为 934 年）重建，并以共享节点处理相邻控制面。
- 楚、荆南：依据 943 年分图向前推定。
- 后蜀、南汉：依据 954 年分图向前推定；后蜀 934 年建国初期的州镇范围仍需同年材料复核。
- 燕云南缘：同年图足以支持军事前沿表达，因此单列过渡带，但不视为第二条精确国界。

## 地点口径

地点 ID、名称和坐标与 `data/seed/locations.ts` 对齐。辽在当前站内地点集中没有上京条目，故以同年图南缘的重要州府幽州作为区域内核对点，不将其标作辽都城。

## 资料与限制

本地校勘页图的元数据和 SHA-256 登记在 `gis/sources/five-dynasties-atlas-index.json`。扫描图、配准栅格和本机绝对路径均不进入仓库；`sources.json` 中本地图集条目全部为 `redistributable: false`。

当前只发布 WGS84 网页尺度 GeoJSON，尚无 934 年 QGIS 工程或 GeoPackage，也未逐州完成拓扑校勘。后续 GIS 编辑应建立权威编辑源，不应把发布层当作现代测绘精度的行政边界。

# 固定 943 地区母版

供后续地图维护者使用：修改共用线段或地区归属后，重新生成网站全部年份；不要单独编辑某年的国家外环。

## 表达口径

全部 907—979 年使用同一套母版。以用户提供的《中国历史地图集》第五册 943 全图为参考，手工概括紫色界线中线，保留明显转折；经纬网控制点作投影坐标校准。它是中等精度历史表达，不是逐年配准或精确测绘。

快照的 `anchorYear: 943` 是地理参照年；`validFromYear`、`validToYearExclusive` 才是归属生效区间。加载校验要求每个面覆盖完整生效区间，不要求945年以后建立的政权反向覆盖943年。

21 个基础地区进一步拆为主要割地所需分区。前后蜀共用整块蜀地；不显示秦凤等小范围进退。燕云、淮南及主要灭国兼并按年末归属表合并面。943、934、949、954、959 不再进入独立几何分支。

吐蕃诸部、西域、北方诸部、洱海—大理、高丽一带及交趾等单独发布为 `reference-943`，默认关闭，可按需打开；它们不进入年度归属面或年末政权计数。不宣称整个展示区间由同一国家控制，侧栏不把907—979显示为其国祚。不确定性写在来源说明中，不再创建“归属待考”国家。

### fixed-943.4 水域与退出规则

`polityId: null` 允许有据退出、无明确接收方的分区不显示，必须有说明与来源；不能以缺少某年资料直接推断灭亡。无缝检查依据当年实际有归属的分区，不再要求补满943总图。`displayName` 可在不改变控制面或政权ID的情况下随年代改名（清源军／平海军）。

现代水库不再从历史陆地扣除；天然湖泊保留，斋桑湖的天然起源与现代扩张例外单独注明。`natural-water.geojson` 用于统一显示，`outlines.geojson` 用于不含湖岸的悬停和选中边线；不要改回直接描画 Polygon 全部环。详细依据见 [名称与水域校核](name-and-water-review.md)。

## 编辑源与生成

- `master-943.json`：参考图像素坐标下的共享线段、命名面内种子、经纬网控制点。相邻两区只有一份公共边。
- `ownership.json`：有效年份、归属、来源及概括说明。小分区的内部界不等同州县界。
- `master-regions.geojson` 与 `partition.geojson`：生成的地理母版及可转移分区。
- `master-calibration-report.json`：定位残差，仅表示经纬网拟合质量，不能当成历史边界精度。
- `generation-report.json`：当前73年几何检查及文件摘要；`referenceYears` 留存旧五套图的审计，与现行年份明确分开。

从项目根目录运行：
```powershell
& 'C:/Program Files/QGIS 4.0.2/bin/python-qgis.bat' scripts/maps/generate-continuous-atlas.py
```

脚本使用本地已下载的 Natural Earth 1:10m Land / Lakes 原始矢量文件，不访问网络或扫描图。缺少原始自然地理文件时需要先恢复它们；不要用现代行政区替代。

线网形成的每个面必须且只能命中一个命名种子；断线、交叉碎片或缺名直接报错。坐标统一转换后裁切陆地、扣除真实湖泊。沿海外包络不是海疆，并明确排除台湾及日本主要岛屿，避免误并入闽、辽等政权；海南和有依据的沿海多面保留。

旧五套发布图、`reference/` 和旧接缝包络只保留作参考。正常生成不改写它们，年份注册表不加载它们。扫描影像不进入仓库或发布目录。

### fixed-943.3 局部校勘

以现有晋图（943）、吴／闽合页（934）、周图（959）的图上纪年和经纬网为首要依据，修订晋辽关南凹入区、淮南北缘、闽与吴／吴越的共享界。分国图的明显转折按网页尺度概括并逆算回母版像素坐标，不改变总图控制点或范围外缘。文件标签、SHA-256、纪年和用途见 `master-943.json.regionalReview`；仍不分发扫描图。

寿州在吴／南唐一侧，淮南按既定阶段模型在958年整体转交后周（不新增957年局部战线）；瀛莫先属辽，959年归后周，同时保州仍留中原侧；建州所在闽内陆区按943年殷、945年南唐、975年宋转换。不得以959年周图倒推943年辽界。测试同时检查相邻城池，避免只为单个点制造凸起或将邻城一并划错。

## 验收

```powershell
& 'C:/Program Files/QGIS 4.0.2/bin/python-qgis.bat' scripts/maps/test-fixed-master.py
npx vitest run tests/continuous-atlas.test.ts tests/map-year-records.test.ts tests/map-context.test.tsx --maxWorkers=1
```

检查每年有效归属、固定覆盖范围、全部多面与孔洞、面重叠、海岸、面内标签、前后蜀相同轮廓、主要都城所在面与范围外岛屿。几何连续不等于史实精确；特别是河北军镇、闽内部界及早期北方地方控制仍是概括。没有主张完成周边诸部的逐年政治沿革。

发布数据在 `public/maps/continuous/`，注册表在 `data/maps/continuous-registry.json`。前端按阶段复用缓存，失败时显示错误，不退回旧方框。更新本地数据后刷新浏览器，避免开发期的内存缓存保留上一版。

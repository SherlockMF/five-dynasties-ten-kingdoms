# 小宇宙“五代十国”逐字稿对抗式校勘

日期：2026-08-31  
范围：逐字稿 01—06  
检查粒度：按源文件全部时间段通读；对可疑断言按“时间码 + 断言 + 风险 + 修订”记录。网站版保留 25 条最高优先级问题，不把逐字稿全文复制入库。

## 结论

这批逐字稿适合充当叙事线索，不适合直接充当事实数据库。主要风险不是偶发错别字，而是四类系统性问题：

1. **源文件污染**：第4、5集首尾含相邻节目内容，第6集末尾混入清初努尔哈赤家族内容；第4集十六州清单有缺段。
2. **叙事层级混淆**：史实、史家笔法、后世传说、小说人物和主持人反事实推演没有标签区分。
3. **绝对化因果**：频繁用“唯一”“彻底”“全部”“从此再无”等词，把长期制度变化压缩成一人一事。
4. **专名与年代错位**：南吴—南唐谱系、楚亡与吴越纳土年代、契丹人物关系等处存在可阻断发布的硬伤。

## 分集阻断清单

### 01 黄巢起义

- `00:00—00:10`：907—960与907—979是观察范围差异，不应说只有一种算法；“十国都是五代附属小弟”不成立。
- `00:10—00:20`：府兵、气候、科举均被单因化；应改成结构性背景。
- `00:45—00:55`：皮日休《牡丹》、黄巢“屠尽五姓七望”与门阀消失的因果链证据不足。
- `01:10—01:15`：黄巢遁入空门是异说；黄皓不宜确定称为其子。

### 02 朱温灭唐建后梁

- `00:02—00:05`：爵位不能按封号字数机械判断等级。
- `00:40—00:42`：李克用在907年前后使用何年号存在文献整理差异，不能无来源定论。
- `00:49—00:51`：“三矢”应标注为《新五代史》的著名史家叙事。
- `00:55—01:05`：朱温覆亡不能只归因于宫闱情色；“至少守丧四十九日”是时代错置的民俗标尺。

### 03 沙陀李姓的后唐

- `00:14—00:17`：燕不入“十国”不是因刘守光残暴；灭燕也不等于收回后来定义的全部十六州。
- `00:20—00:28`：“五十万大军”不可直接当现代统计；契丹人物亲属关系有ASR自相矛盾。
- `00:35—00:50`：后唐通常记作923—936；“除吴、南汉外全部臣服”混淆外交名义与主权。
- `01:00—01:20`：李嗣源改革被写成废除所有地方税、清除全部宦官、彻底解决藩镇世袭，均应降格为具体政策。

### 04 石敬瑭与燕云十六州

- `开头/结尾`：跨集污染，阻断入库。
- `00:35—00:45`：十六州口播列表缺段，现代位置还混入明代山海关语境；地图必须另用校订名目。
- `00:25—00:40`：“儿皇帝”和密信三条款要拆成史源可证事实与流行概括。
- `00:45—01:00`：“华北完全无险可守”“澶渊前唯一目标”是绝对化判断。

校订名目：幽、蓟、瀛、莫、涿、檀、顺、新、妫、儒、武、云、应、寰、朔、蔚。

### 05 契丹灭后晋与短命后汉

- `00:00—00:25`：“傀儡国”需要解释依赖程度；将领“本可必胜”的说法属于反事实。
- `00:30—00:40`：耶律德光被起义者杀死和剖心遗言不宜当史实；较稳妥结论是南归途中病卒。
- `00:40—00:55`：沙陀直接等同匈奴、刘姓源自汉匈和亲，属于无证据的族源串联。
- `01:05—01:25`：杨行密已于905年去世，不可能在906年钟传死后再攻江西；徐温、徐知训指代混乱；杨隆演称号也错位。

### 06 后周做嫁衣与大宋统一

- `结尾`：清初内容与本专题无关，剔除。
- `00:35—00:55`：陈桥兵变参与者有史源记录，但预谋程度、警报真伪和临终警告不能按剧本还原。
- `00:50—01:00`：韩通不是“唯一受害者”，《续资治通鉴长编》记其妻子家属亦遇害。
- `01:10—01:25`：楚亡通常以951年为节点；钱俶纳土发生于978年宋太宗朝。
- `01:20—01:35`：李煜毒杀与小周后故事存在文献冲突；太原“龙脉被断”只能列为传说。

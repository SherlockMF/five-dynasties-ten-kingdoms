# 北齐 / 北周 → 隋：Snapshot Map V1 来源台账

核验日期：2026-09-19。四张图均为 **approximate**，不是 verified，也不是逐年 GIS 重建。

## 阅读范围与证据边界

V1 只画东经 106°—123°、北纬 26°—40°的中东部比较窗口，帮助比较北方东西分立、南北对峙和统一。西部、岭南、东北边缘及域外政权未完整绘制；窗口裁切线不是国界，留白不代表无人统治。海岸仅作现代自然地理定位，不表示六世纪海岸。不使用现代省界。

现有可复核、许可清楚的参考图分别是 **546 年、约 572 年**，不是四个目标年份的原图。因此只采用其概括边界和空间关系，再按纪年史料调整政权归属与江淮前线。文献能证明易手和大致战区，不能证明逐段精确界线。尤其 550 年梁已处侯景之乱中，南方色块仅表示梁的历史地域背景，不能理解为建康朝廷实际控制的整块疆土。

## 重绘流程与可复核材料

`data/maps/northern-qi-zhou-sui/` 保存来源采样、生成后的坐标及署名许可；`scripts/maps/build-northern-qi-zhou-sui.py` 保存确定性的重绘流程。原图政治路径按 SVG 控制点采样；海岸、淮河/长江参考线按已查阅底图概括取点。剪裁与多边形运算用于闭合拓扑，**不是年份插值**。同一阶段各政权共享接触线；区域色值从 canonical Dynasty 获取。

地图属于上述原图的修改作品，不宣称完全独立原创；未复制完整历史地图图片或出版物版面。派生地图数据连同修改说明按 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 发布，署名 Zunkir / Kanguole；此许可仅覆盖注明的地图资料，不改变整个代码仓库许可。UI 提供来源和许可链接。

## 未采用的资料与限制

- Commons `Sui conquest of Chen.png` 标有可靠性争议，未用作边界来源。
- `Cheui Dynasty 581 CE.png` 文件名与说明中的 589—609 年不一致，未用作 581 年依据。
- 610 年隋图不直接用于 589 年。
- 参考图城市点有位置误差，未复制其城市标注；labelPoint 是政权文字的排版锚点，不是都城坐标。
- 来源许可与几何合法性不等于历史边界经过学界验证。需要更严格精度时，应先补充同年专业图集与逐段证据，再提高 accuracyLevel。

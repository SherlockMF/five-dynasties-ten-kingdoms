# 人物史料问答与模型结合

目标：按用户要求保留无模型的基础问答，配置模型后自动结合人物资料、检索史料及本地规则结果回答；人物设定的复制入口只放在随意聊中。

- [x] API：复用已有模型配置。历史模式先生成本地结果；配置完整时调用模型并附带依据和近期对话，否则直接返回本地结果。模型失败时返回本地结果，注明退回原因；客户端取消不触发退回。
- [x] 提示词：历史模式限定事实依据，区分本地规则答复、原始人物资料与检索线索，不把已有助手发言当作证据。保留自由模式的角色演绎。
- [x] 界面：人物设定仅随意聊可见；模型回答注明结合史料生成，来源作为背景依据，失败退回本地时说明。
- [x] 验证：先测试未配置、已配置、错误/超时、取消和追问，再检查界面切换、typecheck、限定 ESLint。真实模型密钥不改动；联网模型调用用模拟服务验证。

完成验证：5 个相关测试文件共 119 项通过；typecheck 与本轮 7 个 TypeScript 文件 ESLint 通过。浏览器确认李昪问历史中不出现人物设定，切换随意聊后出现，切回后移除。模型成功、失败、超时和客户端取消均通过模拟服务测试，未使用真实模型密钥进行调用。

改动文件：`app/api/person-chat/route.ts`、`lib/ai/person-chat-provider.ts`、`lib/ai/person-chat-schema.ts`、`lib/ai/persona.ts`、`features/people/person-chat.tsx`、`tests/person-chat-route.test.ts`、`tests/person-chat.test.tsx`。未更改环境配置、未部署。

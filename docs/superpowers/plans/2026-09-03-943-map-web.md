# 943 年高保真互动地图前端 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有历史网站中用 MapLibre 渲染 943 年真实地理底图与 GIS 疆域，同时保留现有年份、事件、政权详情、键盘替代视图和错误降级能力。

**Architecture:** `HistoricalMap` 继续负责年份、选择状态和右侧列表；仅当年份为 943 且 GIS 发布数据有效时切换到客户端 `HighFidelityMap`。底图由 Protomaps PMTiles 与 Mapterhorn DEM 组成，疆域和地点使用本地 GeoJSON；其他年份继续使用现有 D3/SVG 示意图并显示“示意数据”。

**Tech Stack:** Next.js 16.3.3、React 19.2.8、TypeScript 5.9.3、MapLibre GL JS 6.7.0、PMTiles 4.5.0、@protomaps/basemaps 5.7.2、Zod 4.5.4、Vitest、Testing Library、Playwright。

## Global Constraints

- 只把 943 年标记为高保真；不得把该疆域套用到其他年份。
- 地图默认二维俯视，允许山体阴影，不默认启用 3D terrain 或倾斜视角。
- 底图必须移除现代道路、建筑、现代行政边界、POI 和现代地名。
- MapLibre、底图、DEM 或 GeoJSON 任一失败时，页面必须保留 SVG／列表降级视图。
- 现有 Zustand store 与 URL 序列化仍是唯一交互状态，不新增并行状态系统。
- 键盘政权列表是地图的完整等价入口，Canvas 不是获取详情的唯一方式。
- 页面必须显示 OSM、Protomaps、Mapterhorn 与历史疆域来源署名。
- GeoJSON 是 GIS 计划的发布产物，前端不得修改或复制几何坐标。

`atlas-types.ts` 定义：

```ts
import type { FeatureCollection, MultiPolygon, Point, Polygon } from "geojson";

export type AtlasAccuracy = "attested" | "reconstructed" | "approximate";
export type AtlasBoundaryKind = "controlled" | "influence" | "disputed";
export type AtlasSourceRecord = {
  id: string;
  title: string;
  reference: string;
  role: "georeference" | "cross-check" | "geography";
  license: string;
  redistributable: boolean;
  note: string;
};
export type AtlasRegionProperties = {
  id: string;
  dynastyId: string;
  name: string;
  validFromYear: 943;
  validToYearExclusive: 944;
  boundaryKind: AtlasBoundaryKind;
  accuracyLevel: AtlasAccuracy;
  verificationStatus: "verified" | "reviewed";
  sourceRefs: string[];
  disputedNote?: string;
  labelLongitude: number;
  labelLatitude: number;
};
export type AtlasPlaceProperties = {
  id: string;
  name: string;
  locationId?: string;
  placeKind: "capital" | "prefecture" | "landmark";
  sourceRefs: string[];
};
export type AtlasDataset = {
  realms: FeatureCollection<Polygon | MultiPolygon, AtlasRegionProperties>;
  disputed: FeatureCollection<Polygon | MultiPolygon, AtlasRegionProperties>;
  places: FeatureCollection<Point, AtlasPlaceProperties>;
  sources: AtlasSourceRecord[];
};
export type AtlasProjector = {
  revision: number;
  project: (coordinates: [number, number]) => [number, number] | null;
};
```

`atlas-schema.ts` 并发请求 `/maps/943/realms.geojson`、`/maps/943/disputed.geojson`、`/maps/943/places.geojson`、`/maps/943/sources.json`，检查 HTTP 状态、FeatureCollection、Polygon/MultiPolygon/Point 类型、年份、枚举、坐标和非空来源；把 GDAL 导出的 `sourceRefs` JSON 字符串转换为 `string[]`，并确认每个引用都能在来源台账中找到。AbortError 原样抛出，其他错误带文件名。

# 954 Atlas Snapshot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a source-qualified 954 historical atlas snapshot without extending its boundaries to neighboring years.

**Architecture:** Follow the existing 934/949/959 snapshot contract: static GeoJSON and source metadata are loaded through the shared MapLibre runtime, while `MapYearRecord` selects the snapshot for exactly one year. Tests validate temporal scope, active polity coverage, topology, place placement, and provenance before runtime registration.

**Tech Stack:** TypeScript, Vitest, GeoJSON, MapLibre GL, JSON source ledgers.

## Global Constraints

- Do not copy scanned atlas images into the repository or publication output.
- Do not record local absolute paths.
- Register the snapshot for 954 only; 953 and 955 remain illustrative.
- Mark Southern Tang, Wuyue, Later Shu, and Southern Han as reconstructed; mark Later Zhou, Northern Han, Liao, and Jingnan as approximate.
- Controlled realm interiors must not overlap.

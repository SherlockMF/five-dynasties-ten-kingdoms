# 人物关系与对话改造

**目标：** 按用户截图改为四向连线、全生平关系、顶部气泡对话浮窗及自然的本地规则问答。

**实现：** 保留现有 React Flow、人物和事件资料库、聊天 API 与画像。人物页不再使用全站默认年份过滤；地图和时间线的年份行为不变。聊天基础模式只读本地资料，按问题意图回答，使用近期问题解析追问；来源单独展示，角色表达不冒充史料原文。

- [x] 关系：自定义四向节点，按节点相对位置选择端点；默认展示全部一度关系，关系年份显示在详情。
- [x] 布局：简介顶部放气泡按钮；图与简介并列，图在桌面粘性定位；关系列表移到全宽下方；画像来源收起但参考状态常显。
- [x] 对话：原生 dialog 浮窗、独立滚动、关闭返回焦点；本地身份、生卒、关系、事件、原因/结果/影响、异说、招呼和有限追问规则。
- [x] 验证：相关 Vitest、typecheck、限定 ESLint、桌面和手机浏览器检查；不部署或提交。

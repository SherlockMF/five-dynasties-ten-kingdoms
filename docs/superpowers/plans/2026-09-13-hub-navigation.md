# 总站与专题层级修正

根据用户对页面结构的明确修正，根首页不再作为五代十国首页。此项覆盖此前 TASK 0—4 记录中关于 `/` 仍展示五代首页的约定。

## 结构

- `/`：独立总站，介绍探索方式、选择专题；不挂载朝代地图、年份选择器或问史抽屉。
- `/series`：保留为同一专题选择入口。
- `/series/five-dynasties`、`/series/northern-qi-zhou-sui`：对应专题首页，标题直接显示专题名称。
- 专题桌面顶部导航和移动底部导航按视口显示，移除原重复的第二行专题导航。
- 品牌返回总站；专题首页返回当前系列；切换专题返回总站。五代专题仍保留资料与问史入口。
- 五代导读回链改为 `/series/five-dynasties#reading-paths`；首页地图预览保留 series route context。
- `/map?year=936` 等旧功能入口继续可用；不更改历史数据、Remote 或年份范围，不进入 TASK 5。

# 943 年高保真历史地图设计

状态：待用户审阅
日期：2026-09-03

## 1. 目标

先以 943 年为样板，把当前抽象 SVG 疆域图升级为可缩放、可查询、具备真实地理轮廓的历史地图。地图需要同时满足两件事：

- 地理底图可靠：海岸线、主要河流湖泊和山地起伏与真实地理基本一致。
- 历史表达克制：疆域边界明确区分“史料可证”“推定”“争议”，不把近似重建伪装成精确测绘。

本版完成后，它应成为后续 907—979 年逐年扩展的统一数据与渲染架构，而不是仅供展示的一张静态图片。

## 2. 成功标准

- 中国与东亚的整体轮廓可一眼辨认，不再出现矩形或任意多边形式疆域。
- 943 年主要政权均有独立、可点击的疆域图层：后晋、契丹／辽、南唐、吴越、闽、楚、南汉、后蜀、荆南等。
- 底图不展示现代道路、现代行政区、商业兴趣点和现代地名。
- 山地、水系、海岸线与历史疆域使用同一套坐标体系，缩放和平移时始终对齐。
- 疆域详情能显示来源、重建方法、精度等级和争议说明。
- 断网、瓦片失败、WebGL 不可用或疆域数据损坏时，不出现空白页，能够给出状态提示并回退到现有示意图或文字列表。

## 3. 核心决策

采用“QGIS/GDAL 制图生产 + MapLibre 浏览器渲染”的双层架构：

```text
QGIS / GDAL（资料配准、描绘、拓扑校验）
  └─ 943.gpkg（唯一编辑源）
       ├─ realms             政权疆域
       ├─ disputed_areas     争议与模糊区域
       ├─ places             都城、州府与关键地点
       └─ provenance         来源、精度与校勘记录
            ↓ 可重复构建
       943.geojson（网站发布产物，WGS84）

MapLibre GL JS（网站交互渲染）
  ├─ Protomaps PMTiles       陆地、海岸、水系基础
  ├─ Mapterhorn DEM          山体阴影，默认二维俯视
  ├─ 943 GeoJSON             疆域、争议边界、标签点
  └─ 现有年份状态、事件点与详情面板
```

QGIS MCP 不作为依赖。当前电脑已有 QGIS 4.0.2、GDAL、`ogr2ogr` 和 `gdalwarp`，可以用工程文件与命令行稳定复现数据生产过程。日后即使接入 QGIS MCP，也只改善操作效率，不改变数据格式或网页架构。

## 4. 数据来源与使用边界

### 4.1 地理底图

- Protomaps/OSM：提供海岸、陆地、水系及必要的自然地理要素。网站必须保留 OSM 与 Protomaps 署名。
- Mapterhorn：提供 Terrarium DEM，用于山体阴影。网站必须按其要求保留署名。
- 生产版优先把目标区域裁切为自托管 PMTiles；样板阶段允许使用官方远程端点验证样式与交互，但数据 URL 必须集中配置，使切换到自托管无需改动渲染逻辑。
- 自托管文件不直接盲目提交到 Git。先记录大小与许可，再决定放入项目静态资源或支持 HTTP Range/CORS 的对象存储。

### 4.2 历史疆域

- 1935 年《中国历史商业地图集》中 936—946 年地图：公版，可用于地理配准与基础轮廓参考。
- 用户提供的 943 年水印地图：仅作交叉核对，不复制、裁切或作为网站直接素材发布。
- CHGIS：用于核对历史地名、行政层级、海岸与水系语境；仅在具体数据许可允许时再纳入发布产物，否则只记录为研究参考。
- 六集逐字稿：用于政权沿革、事件与叙事校对，不单独承担疆域几何证据。
- 其他扩展史料：必须记录书名、卷次或稳定链接，并继续沿用站内“扩展”角标规则。

疆域几何是基于多来源的独立重建，不描摹或分发来源不明、带水印的商业图片。

## 5. GIS 数据生产流程

1. 在 QGIS 中建立统一工程，编辑坐标系使用适合东亚范围制图的投影，发布时统一转换为 EPSG:4326。
2. 对公版历史地图设置控制点并配准；控制点优先选择海岸转折、主要河流汇合、稳定城址等，避免依赖现代省界。
3. 结合历史政区、山川阻隔、州府归属与同期地图，逐一描绘政权控制范围。
4. 把无法确定的区域拆为 `disputed_areas`，而不是强行并入某一政权。
5. 执行拓扑检查：修复自相交、非法环、无意重叠与缝隙；允许的争议重叠必须显式标记。
6. 通过版本化脚本从 `943.gpkg` 导出简化后的 `943.geojson`，保持字段、坐标精度和几何简化参数可复现。

`943.gpkg` 是唯一人工编辑源，GeoJSON 只是构建产物，禁止在两个文件中分别手工维护。

## 6. 疆域数据契约

每个政权或争议区要素至少包含：

| 字段 | 含义 |
| --- | --- |
| `id` | 稳定的要素标识 |
| `dynastyId` | 与现有站内政权数据关联的标识 |
| `name` | 页面显示名称 |
| `validFromYear` | 生效年份，包含 |
| `validToYearExclusive` | 结束年份，不包含 |
| `boundaryKind` | `controlled`、`influence` 或 `disputed` |
| `accuracyLevel` | `attested`、`reconstructed` 或 `approximate` |
| `verificationStatus` | 校勘状态 |
| `sourceRefs` | 来源标识数组，指向出处记录 |
| `disputedNote` | 争议说明，无争议时为空 |
| `labelPoint` | 经过人工调整的标签锚点 |

政权颜色、中文名称和详情正文继续由现有站内内容数据管理；GeoJSON 只存地图渲染与证据关联所需信息，避免重复维护长文本。

## 7. 地图图层与视觉设计

自下而上的固定图层顺序如下：

1. 海洋与纸张色背景。
2. Protomaps 自然地理底图：陆地、海岸、主要河湖；关闭现代道路、建筑、POI、现代行政界与标签。
3. Mapterhorn 山体阴影：低对比度、偏墨灰，不覆盖文字；默认不开启透视 3D 地形。
4. 必要的历史水系或海岸修正层。
5. 政权控制区填色：低透明度宣纸色块，保持地形可见。
6. 政权边界：朱砂、黛青、赭石等站内色系；可靠边界用实线，推定边界用短虚线，争议区用纹理或交错虚线。
7. 都城、州府、事件点与行军路径。
8. 政权标签、地图控件、图例、署名和详情面板。

整体延续网站的纸张、墨色、朱砂和旧金配色，不照搬现代导航地图，也不使用夸张的 3D 视角。地形只负责解释山川阻隔，疆域与历史信息始终是第一视觉层级。

## 8. 页面交互

- 打开 943 年时，地图自动定位到东亚总览；保留缩放、平移、全图复位。
- 悬停疆域只做轻微描边增强，避免整块高亮遮住地形。
- 点击疆域后复用现有详情面板，展示政权概况、时间范围、来源与精度。
- 点击争议区时优先展示争议说明和不同史料口径。
- 事件点沿用现有年份与分类筛选；疆域选择和事件选择使用统一的 URL 状态规则。
- 键盘用户可以聚焦地图外的政权列表并触发同一选择；地图不是获取详情的唯一入口。
- 地图角落常驻图例与署名，窄屏时折叠为可展开面板。

943 年以外的年份在高保真数据尚未制作前继续使用现有示意图，并明确显示“示意数据”标签；不得把 943 年疆域套用到其他年份。

## 9. 前端集成边界

- 新增一个仅在客户端加载的 MapLibre 地图组件，避免服务端访问 WebGL 或浏览器对象。
- PMTiles 协议只注册一次，地图实例在组件卸载时彻底释放。
- 底图、DEM、疆域与事件分别建立 source/layer，任何单层失败都不阻断其余图层。
- 样式配置、数据 URL、视野范围和 attribution 集中管理，不散落在 React 组件中。
- 现有年份 store、政权详情、事件详情和 URL 序列化逻辑继续复用，不另建并行状态系统。
- 943 年以外继续走现有 SVG 渲染器，直到对应年份的正式 GeoJSON 通过验收。

## 10. 失败与降级

- WebGL 不可用：显示说明并回退到现有 SVG 示意图及政权列表。
- 底图或 DEM 请求失败：保留纯色背景与历史疆域，显示非阻断提示。
- 943 GeoJSON 加载或校验失败：不显示可能错误的边界，回退到 SVG 并标注“示意数据”。
- 单个要素缺少来源或精度：构建失败，不允许以默认“已证实”状态发布。
- 远程端点不可达：样板可降级；进入生产前必须完成自托管或确认稳定的部署方案。

## 11. 验证方案

### 数据验证

- GeoJSON schema 校验：必填字段、年份范围、枚举值、来源引用。
- 几何合法性与拓扑检查：自相交、空几何、异常重叠、超出研究范围。
- 固定抽查关键轮廓：后晋—契丹边界、河西走廊、四川盆地、江南诸国与岭南。

### 代码验证

- 图层配置单元测试：顺序、过滤条件、颜色映射、争议线型和 attribution。
- 943 年／非 943 年渲染分流测试。
- 加载失败和 WebGL 不可用时的降级测试。
- URL 状态、点击选区、事件点与详情面板联动测试。

### 浏览器验收

- 桌面与移动端检查缩放、平移、复位、选择、图例和面板。
- 视觉检查海岸、水系、地形与疆域对齐。
- 确认没有现代道路、现代行政区、商业 POI 和不应出现的现代标签。
- 确认地图署名、来源、精度与争议信息均可访问。

## 12. 首版范围与非目标

首版只交付 943 年高保真样板及其可复用的数据管线。以下内容不在本次范围内：

- 一次性完成 907—979 年全部年度疆域。
- 县级或逐村级精确重建。
- 默认 3D 地形、卫星影像或现代导航功能。
- 安装或开发 QGIS MCP。
- 未经许可分发 CHGIS 数据或用户提供的水印地图。
- 在本次开发中完成正式公网部署和大体积地图资产托管迁移。

# 954 年地图校勘与界面修正设计

## 目标

修正 954 年地图当前存在的三个界面缺陷，并把疆域可信度从“人工概括后直接称为正式重建”调整为可核验的 GIS 工作流。完成后，用户点击“复位全图”能看清当前年份全部政权，图例固定在地图画布内，右栏不再露出深色空洞；未经 QGIS 配准描边的疆域不得标为正式重建。

## 界面与交互

### 复位范围

- 复位范围由当前 `AtlasDataset` 的 `realms`、`disputed` 与 `places` 动态计算，不再使用底图允许范围 `ATLAS_BOUNDS`。
- `ATLAS_BOUNDS` 只继续作为拖动限制。
- 复位时使用地图画布的实际宽高和统一安全边距，确保南汉、辽等最外侧疆域与标签均处于可视区。
- 年份切换仍保留当前相机；只有用户点击“复位全图”时才重新适配当前快照。

### 图例与右栏

- 图例移入地图画布容器，定位基准不再包含来源说明区。
- 桌面端图例放在地图左下角、位于“复位全图”上方；窄屏时允许横向换行，不遮挡归属信息和事件标记。
- 地图主体网格背景统一为纸色。右栏外层填满网格高度，只有政权列表内部设置最大高度和细滚动条，避免露出父层深色背景。

## 954 年数据分级

### 当前数据

当前 `public/maps/954/realms.geojson` 是少量经纬度节点组成的网页尺度人工概括，没有 QGIS 工程、控制点记录或共享拓扑，因此先降级为“阶段概括”。南唐、吴越、后蜀、南汉即使使用了 954 年同纪年图页，也不能继续显示为“正式重建”；后周、北汉、辽和荆南继续明确标为邻年推定。

### QGIS 校勘流程

1. 为 954 年四张同纪年图建立本地 QGIS 工程，使用图面经纬网交点作为控制点，配准到 WGS84。
2. 在共享线层中沿图集紫色政权边界描线，海岸段吸附到统一自然地理海岸线；相邻政权共用同一条拓扑边。
3. 从共享边界生成南唐、吴越、后蜀、南汉 Polygon，记录控制点、源图 ID、配准残差和人工判断说明。
4. 北方仍使用 949/959 邻年证据，但在界面与属性中保持 `approximate`，不得与同年校勘范围使用同一可信度标签。
5. 从 GIS 编辑源导出网页 GeoJSON，并只做保持拓扑的轻量简化。扫描图和绝对路径不进入仓库。

## 数据与组件边界

- 新增一个纯函数，根据 GeoJSON 几何计算当前快照的可视 `bbox`；复位按钮只依赖这个结果。
- `HistoricalAtlasMap` 接收图例可用类型并在地图画布内部渲染图例。
- `MapYearRecord` 与 manifest 文案区分“正式重建”“阶段概括”“示意边界”；只有存在配准记录和 GIS 编辑源的快照可使用“正式重建”。
- 本地 QGIS 成果放在 `gis/954`，发布产物放在 `public/maps/954`；来源账本继续只保存元数据。

## 失败与降级

- 当前快照几何为空或 bbox 无法计算时，复位按钮退回统一初始视野，不抛出页面级错误。
- GIS 校勘未完成前，954 保持可用，但显示“阶段概括”及限制说明。
- 正式快照载入失败时仍按现有机制降级为年度示意边界。

## 验收

- 954 年点击“复位全图”后，八个政权的疆域或推定范围均完整进入地图画布。
- 图例始终位于地图内部，不覆盖来源说明；桌面和移动端均可读。
- 右栏滚动到底后，下方仍为纸色，不出现深色矩形空洞。
- 当前粗略 954 数据不再显示“正式重建”；完成 QGIS 校勘并导出后才恢复正式标识。
- GeoJSON 相邻边无缝隙或重叠，几何有效，且南方边界在网站常用缩放级别保留参考图的主要曲折形态。
- 单元测试覆盖 bbox 计算、复位调用、图例容器和可信度文案；最后执行 TypeScript、ESLint、相关测试与一次桌面浏览器冒烟验收。

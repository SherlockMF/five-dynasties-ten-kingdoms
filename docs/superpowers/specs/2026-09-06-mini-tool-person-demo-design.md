# 小工具人物对话演示与提示词

## 已确认的方向

人物详情保留画像、小传，增加离线预设对话和可供用户带到其他 AI 工具使用的人物提示词。明确标注“预设剧情演示，非实时 AI”；演绎不是历史原话。

## 实现选择

采用构建时复用原项目资料、运行时点击预设问题的方案。相比为所有人物另写剧本，此方案避免未经核实的新增史实；相比自由输入关键词匹配，它不会让用户误以为能够理解任意问题。暂不增加自由输入框、网络请求或模型服务。

## 入口与操作

- 在人物详情内提供“对话演示”和“查看人物提示词”，切换内容不叠加多个弹窗。
- 对话显示人物姓名、演示标识、用户问题和回答；提供生平、关联事件、资料边界等预设问题。
- 选择事件后提供背景、经过、结果、影响的预设追问；回答始终对应当前人物及事件，不用上一个人物的内容。
- 允许清空当前演示；关闭详情后回到原人物列表位置。演示会话不承诺跨重启保存。

## 内容与数据

- 构建时调用 `lib/ai/persona.ts` 的 `buildPersonPrompt`，导出“问历史”模式提示词，保留原有个人语气、资料书目和事实边界。无需复制服务端 API 或包含任何运行配置。
- `data/person-dialogues.ts` 的手写对白优先使用，旁边标注“角色演绎，非历史原话”，展示对应资料来源。
- 当前手写对白只覆盖石敬瑭与燕云十六州相关事件。其余回答从既有人物、事件记录生成，明确标注“资料说明”，不通过替换人称伪造私人回忆、动机或对白。
- 缺少资料时说明未收录；只为有对应内容的事件字段展示追问按钮。异说、来源不得丢失。

## 提示词展示与复制边界

- 使用带可访问名称的只读多行文本框展示完整提示词，允许选择文本，并提供“选中全部”操作。
- 说明“请使用设备提供的复制操作，再粘贴到其他 AI 工具”；不显示虚假的“复制成功”。
- 不调用剪贴板 API、`execCommand`、外链跳转或下载。
- 普通浏览器的文本选择验证不等于小红书容器的复制验证；容器禁用系统长按菜单，真实复制能力必须由容器实测确认，不能承诺所有设备都支持。

## 修改范围

小工具构建脚本、人物详情渲染、局部样式与相关测试。复用原人物提示词生成函数和已有对白数据，不修改原版 Next.js 页面、对话服务或历史数据。本轮不把地图、时间线、人物关系图的完整还原混入该功能；此前红框及手势未交付改动单独验证并注明状态。

## 验收

1. 所有已打包人物均能查看各自完整提示词，包含演绎标识与事实边界。
2. 预设问答、事件追问、清空和人物切换正确；手写对白与资料说明明确区分。
3. 全选后的选区覆盖完整提示词，不写入剪贴板，不显示复制成功。
4. 手机宽度下提示词无横向溢出，详情可滚动、可关闭，键盘焦点可用。
5. 新增行为测试先失败再实现，运行小工具回归、构建与官方审计，记录包体和未完成的容器实测。

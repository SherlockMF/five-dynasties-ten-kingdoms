# 小工具人物与地图恢复

用户已批准：完整人物画像 + 原项目阶段疆域的离线交互 SVG 地图。

## 实施范围

1. 从 `data/portraits.ts` 和 `public/portraits/series` 复用全部 52 张画像，构建时生成 240×320 WebP，保留艺术创作及参考来源说明。
2. 从 continuous registry 读取全部阶段，严格使用原始 907—979 年映射。构建时预投影、去重 SVG 路径，保留政权名称、配色、疆域轮廓、湖泊和来源说明。
3. 人物卡与弹窗显示画像；地图提供年份切换、区域选择、缩放和当年事件点。移除抽象陆地占位图。
4. 运行时仍为经典脚本和包内资源。ZIP 硬上限 10 MiB；允许为保留核心体验超过 2 MiB 建议值，并记录实际体积。
5. 验证全部画像、完整年份映射、阶段边界、区域交互、移动端显示、静态审计及相关回归；重新打包交付。

## 验收依据

画像必须与原人物 ID 一一对应；地图几何必须来自原发布数据，不能用虚构轮廓替代。年份切换需反映同一 registry 的年末归属。来源和精度说明沿用原数据语义。预投影与适度精度缩减属于展示适配，不能改变政权归属。

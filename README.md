# 山河纪：五代十国互动历史探索

一个以本地类型化数据驱动的 Next.js 历史探索站。当前内容覆盖 875—979：875—906 为“唐末前史”，907—979 为“五代十国主体”。

当前数据快照：74 个事件、52 位人物、35 个地点、17 个核心政权。数字用于描述本次发布快照，不是页面测试依赖的永久总量。

## 功能

- 时间线：按年份查看事件，并筛选“五代主线、十国并立、辽与北方、宋初统一”四条轨道。
- 地图：查看 907—979 年年末简化势力格局、事件 marker、政权详情、当年君主与疆域精度。
- 人物：按政权类别和角色筛选，以人物为中心查看一度关系、简传、异说与来源。
- 事件详情：展示背景、过程、结果、影响、人物、政权、地点、因果链和参考书目。
- 资料与校勘：`/notes` 是方法、出处与六集逐字稿校订入口，不是历史内容主体。
- 问史：在当前页面和年份上下文中检索本地事件证据，明确区分“知识库”“未检索到”和“通用知识 · 非知识库”。

## 来源角标

- `¹`：六集主线，经外部史料核定。
- `²`：六集未覆盖的史料扩展。
- `¹²`：六集提供叙事主线，具体事实由史料补齐。
- `³`：存在影响理解的重要异说，可与前三种角标叠加。

角标可以用鼠标或键盘查看完整说明，并提供无障碍名称。六集播客逐字稿不是最终唯一史料；完整的实际使用范围、事件 ID、争议处理和 `sourceRefs` 审计见[历史内容来源账本](docs/research/2026-08-31-history-source-ledger.md)。

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。当前默认使用本地 `LocalHistoryRepository` 和 mock 问史 provider，浏览核心功能不要求 Supabase 或外部 LLM 凭据；`.env.example` 仅提供未来集成所需的占位键名，不要提交真实密钥。

## 验证命令

```bash
npm run typecheck
npm run lint
npm test -- --run
npm run build
npm run test:e2e
git diff --check
```

Playwright 配置包含 desktop Chrome 与 Pixel 7 两个项目，并由 `webServer` 在 `127.0.0.1:3100` 启动开发服务器。

## 地图精度

地图展示所选年份的年末格局。当前 17 个疆域数据全部标为“示意”：依据史料概括绘制，不代表可精确复原的行政边界；35 个地点坐标也只作位置参照。站点不提供精确 GIS 历史国界、完整行军路线，也不为 875—906 绘制逐年疆界。

## 本地 RAG 边界

问史检索只读取事实层事件的标题、年份、人物/政权/地点名称、摘要、背景、过程、结果、影响、书目与异说提示，单次最多提供 5 条证据。它不进行全文古籍搜索，不读取逐字稿校勘中的错误原句，不调用生产 embedding 或生产 LLM。没有本地证据时会明确显示“未检索到”；用户主动选择通用知识后，回答会标为非知识库内容。

## 当前不包含

账号、会员、评论、CMS、数据库内容发布、自动抓取史料、生产 LLM、精确 GIS 边界和部署配置均不在本轮范围内。
